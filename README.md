# Student Laptop Finder

A responsive web app that helps students browse laptops, search and filter them, read full specifications,
save favorites and compare them side by side.

- **GitHub repo:** https://github.com/Abugabal-117/Laptop-Finder
- **Built with:** HTML, JavaScript (ES modules), Tailwind CSS 4

## Install and build

Requires [Node.js](https://nodejs.org/).

```bash
# 1. install the packages listed in package.json
npm install

# 2. build the CSS once (creates dist/output.css)
npm run build

# or: rebuild automatically while you edit
npm run watch
```

## Run

`fetch()` does not work on pages opened directly as files, so run the site from a local server,
for example **VS Code Live Server**: right-click `index.html` and choose **Open with Live Server**.

## Pages

| Page                | Purpose                                                           |
| ------------------- | ----------------------------------------------------------------- |
| `index.html`        | Home page with live statistics and links                          |
| `laptops.html`      | Catalogue with live search, filters, sorting and favorite buttons |
| `details.html?id=7` | Full details of one laptop                                        |
| `favorites.html`    | Saved laptops with total and average price                        |
| `compare.html`      | Compare 2 to 4 favorites, best values highlighted                 |

## Project structure

```
laptop_finder_yourname/
├─ index.html  laptops.html  details.html  favorites.html  compare.html
├─ src/
│  ├─ input.css            Tailwind setup: themes, plugins, component classes
│  └─ js/
│     ├─ api.js            loads data/laptops.json with fetch
│     ├─ storage.js        favorites, compare list and theme in localStorage
│     ├─ ui.js             laptop card, skeleton, messages, header and footer
│     ├─ compare.js        comparison rows and best-value calculation
│     └─ index.js  laptops.js  details.js  favorites.js  comparePage.js   (one file per page)
├─ data/laptops.json       20 laptops
├─ dist/output.css         generated by Tailwind
├─ assets/                 laptop images
├─ package.json
└─ README.md
```

## Themes

- **Battery Saver Mode** (default): light background with green accents.
- **Performance Mode**: dark background with an orange accent.

The theme switch is in the header of every page. The choice is saved in localStorage and restored on every page.

## Tailwind features used

- `@import "tailwindcss";`, `@theme`, `@plugin` (`@tailwindcss/forms`, `@tailwindcss/typography`)
- Component classes with `@layer components` and `@apply`: `.laptop-card`, `.btn-action`, `.btn-ghost`, `.field`, `.prose-theme`
- `animate-pulse` loading skeletons, hover and focus transitions, responsive `sm:` `md:` `lg:` classes
